# Section: style

## Purpose
- Global UI styling for HUD, menus, inventory, crafting, and mobile controls.

## Key Files
- `src/style.css` contains all UI styles and mobile overrides.

## Highlights
- HUD styling for hotbar, health, crosshair, damage overlay.
- Inventory and crafting layouts with mobile adjustments.
- Menu styling using a tiled background texture and Minecraft-like buttons.
- Mobile joystick and action buttons with touch-friendly sizing.
- CLI input bar at bottom of screen.
