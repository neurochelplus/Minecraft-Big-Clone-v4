## 2026-02-03 - Flawed Custom HTML Sanitization
**Vulnerability:** The custom `sanitizeHTML` function in `src/modding/UIAPI.ts` failed to block several high-risk vectors, including `svg` (allowing XSS), `form` (allowing phishing/CSRF), `base` (hijacking relative links), and `action`/`formaction` attributes (allowing script execution). It also missed checking for `vbscript:` and `data:` protocols and did not normalize attribute values (allowing whitespace obfuscation).
**Learning:** Blacklisting tags and attributes is error-prone. Custom sanitizers often miss "rare" but dangerous tags (`svg`, `math`, `details`) or attributes (`formaction`). Browser quirks (like whitespace in protocols) can easily bypass simple string checks.
**Prevention:** Use a battle-tested sanitization library like DOMPurify instead of rolling your own. If a custom implementation is required, ensure it uses an allowlist (whitelist) approach rather than a blocklist (blacklist), or maintain an extremely comprehensive blocklist that includes modern HTML5 vectors and protocol normalization.
